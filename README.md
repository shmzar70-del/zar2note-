Zar2Note

Offline Music Note Detection for Android

Zar2Note is an Android application designed to detect musical notes using audio input.

Features

- Designed for offline use.
- Audio input for musical note detection.
- HTML-based application interface.
- Intended for musicians and music learners.

Project Files

- "index.html": Entry page for the web application.
- "zar2note6.html": Main application file.
- "manifest.json": Progressive Web App configuration.
- "service-worker.js": Service worker for offline caching.
- "Zar2Note.apk": Android installation package, if included.

Installation

Download the APK from the repository and install it on a compatible Android device. Android may ask you to allow installation from your browser or file manager.

Offline Use

Open the application once while connected to the internet so that the service worker can cache the required files. Then test the application with internet access disabled.

Development Status

This project is under development. Features and compatibility may change between versions.
