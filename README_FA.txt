فایل‌های کمکی PWA برای Zar2Note
================================

این فایل‌ها را در همان پوشه‌ای از مخزن GitHub قرار بده که فایل اصلی برنامه قرار می‌گیرد.

مهم:
1) از فایل HTML اصلی یک نسخهٔ پشتیبان نگه دار. برای GitHub Pages، یک کپی از فایل اصلی را با نام index.html قرار بده؛ فایل اصلی با نام قبلی‌اش هم بماند.
2) داخل بخش <head> فایل index.html این دو خط را اضافه کن:
   <link rel="manifest" href="./manifest.json">
   <meta name="theme-color" content="#6d5dfc">
3) درست قبل از </body> این کد را اضافه کن:
   <script>
   if ("serviceWorker" in navigator) {
     window.addEventListener("load", () => {
       navigator.serviceWorker.register("./service-worker.js").catch(console.error);
     });
   }
   </script>
4) در تنظیمات مخزن GitHub، از Settings > Pages سایت را منتشر کن. PWABuilder به آدرس عمومی HTTPS سایت نیاز دارد، نه آدرس صفحهٔ مخزن.
5) سایت را یک‌بار آنلاین باز کن و قابلیت میکروفون، تشخیص نت و خروجی فایل را آزمایش کن؛ سپس حالت آفلاین را بررسی کن.

محدودیت‌ها:
- این فایل‌ها به‌تنهایی APK یا سورس کامل اندروید تولید نمی‌کنند؛ فقط فایل‌های پایهٔ PWA هستند.
- Service Worker فایل index.html و فایل‌های فهرست‌شده را کش می‌کند. اگر برنامه فایل‌های JS، CSS، صوت یا دادهٔ جداگانه دارد، مسیرهای نسبی آن‌ها را به آرایهٔ APP_SHELL در service-worker.js اضافه کن.
- دسترسی میکروفون در مرورگر معمولاً به HTTPS یا localhost نیاز دارد.
- اگر HTML به فایل‌های بیرونی یا کتابخانه‌های آنلاین وابسته باشد، برای کار کامل آفلاین باید آن وابستگی‌ها هم بررسی شوند.
